How scoring works

  • 10 for every patch deployed.
  • 50 for a Patch My PC logo, which makes the vulnerabilities patchable for a while.
  • 200, 400, 800, 1600 for vulnerabilities patched inside one window. The chain resets when the window closes, so the order you catch them in is worth more than the number.
  • 500 for clearing a board, plus a release package worth between 100 and 5000 that appears twice a level.
  • Three lives. The run ends when the last one goes.

Every run posted here is replayed on the server from its seed and its keystrokes before it is counted, so a score is something the server works out rather than something the browser claims.
